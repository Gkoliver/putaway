# Putaway v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a household-scoped inventory API plus a thin Next.js admin and an Expo iOS/Android app that can put away, find, ask the usual place, and take out by voice or text.

**Architecture:** One TypeScript monorepo. `packages/shared` holds command types, name matching, and interpreter parsing. `apps/web` is Next.js: Drizzle/Postgres, Better Auth, the inventory domain, and API routes that are the only writers. `apps/mobile` is Expo; it records audio or sends text and renders confirmations/clarifications. Voice STT/LLM stay on the server.

**Tech Stack:** Node.js >= 22.13, pnpm, TypeScript, Next.js 15 App Router, Expo SDK 57 (`expo@^57.0.9`), React 19.2.3, Drizzle ORM, Postgres 16, Better Auth, Zod, Vitest, OpenAI audio transcription + structured extract.

## Global Constraints

- TypeScript monorepo: `apps/mobile` (Expo / React Native), `apps/web` (Next.js), Next.js API routes as the only inventory writer, `packages/shared`, Postgres as source of truth.
- User ≠ household. Client sends `household_id`; server accepts it only if a membership row exists.
- Roles: `owner` | `member`. Any signed-in user can create a household and becomes its `owner`.
- Intents: `put_away` | `take_out` | `find` | `find_usual`. Default quantity is **1**.
- Create items and location nodes **only** on put-away. Take-out / find / find-usual never create them.
- Stock lot quantity may be **0**; take-out to 0 **keeps** the row. Do not delete empty lots.
- Find uses lots with `quantity > 0`. If none, fall back to usual-place ranking.
- Find-usual ranks by `put_away_count` desc, then `last_activity_at` desc, including zeros.
- Ignore lots whose location is archived. Archived nodes are not reused for new put-aways.
- Take-out never goes below 0; never borrows from another location. Ambiguous in-stock lots → `which_location?`.
- Confirmations always include item, location path, and resulting quantity.
- Duplicate `(household_id, user_id, client_command_id)` returns the original result; do not apply twice.
- Web: cookie sessions. Expo: Better Auth bearer/session token. Both hit the same Next.js API.
- Expo SDK 57 with `expo@^57.0.9` or later (avoid <= 57.0.8). iOS and Android from day one.
- CI does not automate on-device speech recognition. Interpreter and handler are tested with text.
- No billing, custom wake word, Alexa/Google, photos, expiry, or auto-suggest location on put-away without a path.

```ts
// packages/shared/src/matching.ts
const SIMILARITY_THRESHOLD = 0.85;
const AMBIGUITY_DELTA = 0.02;

export function normalizeName(name: string): string {
  return name
    .trim()
    .toLowerCase()
    .replace(/^the\s+/, "")
    .replace(/\s+/g, " ");
}

function stripPlural(name: string): string {
  if (name.endsWith("shelves")) return `${name.slice(0, -7)}shelf`;
  if (name.endsWith("ies") && name.length > 4) return `${name.slice(0, -3)}y`;
  if (name.endsWith("ses") || name.endsWith("xes") || name.endsWith("zes") || name.endsWith("ches") || name.endsWith("shes")) {
    return name.slice(0, -2);
  }
  if (name.endsWith("s") && !name.endsWith("ss")) return name.slice(0, -1);
  return name;
}

function bigrams(s: string): string[] {
  const compact = s.replace(/\s+/g, "");
  const grams: string[] = [];
  for (let i = 0; i < compact.length - 1; i++) grams.push(compact.slice(i, i + 2));
  return grams;
}

function dice(a: string, b: string): number {
  const A = bigrams(a);
  const B = bigrams(b);
  if (A.length === 0 || B.length === 0) return a === b ? 1 : 0;
  let hits = 0;
  const used = new Array(B.length).fill(false);
  for (const g of A) {
    const j = B.findIndex((x, i) => x === g && !used[i]);
    if (j >= 0) {
      used[j] = true;
      hits++;
    }
  }
  return (2 * hits) / (A.length + B.length);
}

export function namesMatch(a: string, b: string): boolean {
  const na = normalizeName(a);
  const nb = normalizeName(b);
  if (na === nb) return true;
  if (stripPlural(na) === stripPlural(nb)) return true;
  return dice(na, nb) >= SIMILARITY_THRESHOLD;
}

export function bestMatches<T>(
  query: string,
  items: T[],
  getName: (item: T) => string,
): T[] {
  const nq = normalizeName(query);
  const exact = items.filter((item) => normalizeName(getName(item)) === nq);
  if (exact.length === 1) return exact;
  if (exact.length > 1) return exact;

  const plural = items.filter((item) => stripPlural(normalizeName(getName(item))) === stripPlural(nq));
  if (plural.length === 1) return plural;
  if (plural.length > 1) return plural;

  const scored = items
    .map((item) => ({ item, score: dice(nq, normalizeName(getName(item))) }))
    .filter((x) => x.score >= SIMILARITY_THRESHOLD)
    .sort((a, b) => b.score - a.score);

  if (scored.length === 0) return [];
  const top = scored[0].score;
  return scored.filter((x) => top - x.score <= AMBIGUITY_DELTA).map((x) => x.item);
}
```

import type { CommandOutcome, InventoryCommand } from "@putaway/shared";

export async function submitCommand(input: {
  apiBase: string;
  token: string;
  householdId: string;
  clientCommandId: string;
  transcript?: string;
  command?: InventoryCommand;
}): Promise<CommandOutcome> {
  const res = await fetch(`${input.apiBase}/api/commands`, {
    method: "POST",
    headers: {
      "content-type": "application/json",
      authorization: `Bearer ${input.token}`,
    },
    body: JSON.stringify({
      householdId: input.householdId,
      clientCommandId: input.clientCommandId,
      transcript: input.transcript,
      command: input.command,
    }),
  });
  return (await res.json()) as CommandOutcome;
}
